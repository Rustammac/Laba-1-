# 🌿 Эко-активист — Стилизация страницы (внешний CSS)

> Лабораторная работа №2 по дисциплине «Веб-технологии»
> Оформление страницы из ЛР №1 с помощью внешнего CSS-файла

## 🎯 Цель работы

Научиться подключать стили, работать с селекторами, типографикой, цветами, отступами, позиционированием и псевдоклассами.

## 📋 Задание

Оформить страницу из ЛР №1 с помощью внешнего CSS-файла (`style.css`). Требовалось реализовать:

- основной стиль — во внешнем файле; 1 элемент с inline-стилями; 1 правило во внутреннем блоке `<style>`;
- CSS-переменные в `:root` для цветов и шрифтов;
- примеры позиционирования: `static`, `relative`, `absolute`;
- состояния элементов: `:hover`, `:active`, `:focus`, `:visited`;
- контрастность текста не менее 4.5:1.

## 🧩 Реализация

| Требование | Реализация |
|---|---|
| Внешний CSS | Основной блок стилей вынесен в `style.css` |
| Inline-стиль | Точечный inline-стиль на аватаре (border-radius) |
| Внутренний `<style>` | Правило для тени и выравнивания футера |
| `:root`-переменные | Цвета и шрифты страницы заданы через CSS-переменные |
| Позиционирование | Примеры `static`, `relative`, `absolute` на элементах страницы |
| Псевдоклассы | `:hover`, `:active`, `:focus`, `:visited` для интерактивных элементов |
| Анимация | Дополнительно: `@keyframes`-анимация «прорастания» для списка навыков |
| Контрастность | Цветовая пара текст/фон подобрана с коэффициентом контрастности ≥ 4.5:1 |

## 🛠️ Стек технологий

- HTML5 (разметка из ЛР №1)
- CSS3
  - внешние стили (`style.css`)
  - inline-стили
  - внутренний блок `<style>`
  - CSS-переменные
  - позиционирование
  - псевдоклассы
  - `@keyframes`-анимация


## ♿ Доступность

Цветовые сочетания текста и фона проверены на соответствие минимальному контрасту 4.5:1 (стандарт WCAG AA для основного текста).
